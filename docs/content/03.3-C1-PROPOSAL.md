### Traceability types

```ts
type CellRef = { sheet: "Tổng quan 6 cơ sở" | "Cơ sở & danh sách phòng" | "Thông tin các điểm tham quan"; cell: string };
type Verification = "client-supplied" | "normalized" | "derived" | "conflict" | "missing" | "confirmed";
type Sourced<T> = {
  raw: string | null;       // exactly as in the workbook, never edited
  display: T | null;        // what the UI may show; null when nothing may be shown
  source: CellRef[];
  status: Verification;     // "confirmed" only after VNest answers
  rule?: string;            // the written normalization rule, when status is normalized or derived
  clarification?: string;   // open question id from the audit, e.g. "Q13"
};
```

Static content only. The adapter has no price, rate, availability or booking field, and imports nothing from `src/integrations/booking`. A test enforces this (section 4). The indicative rates stay in the JSON draft.

## 4. Tests

`client/adapter.test.ts` runs in the existing `npm test`. It checks:

- **Traceability**:
  - every displayed value has at least one source cell;
  - every `raw` equals the snapshot cell exactly;
  - every non-`confirmed` value carries a status and, where an open question exists, its id.
- **Normalization**: the short-name and city rules give the six values in section 1. A name whose suffix is not its brand is left whole; this is tested with a synthetic row.
- **No silent correction**: the raw Bare Hàn description stays the Đa Kao text and is marked `conflict`. The raw Bare Hyphen address keeps its trailing newlines. Neither reaches the homepage.
- **Static and dynamic kept apart**: the adapter's output has no price, rate or availability key, and the client module imports nothing from `src/integrations/booking`.
- **Area**: `areas` is empty and no property has an area.
- **Combined brand and city filters on the real data**: all 12 combinations in the section 1 table, with exact property ids. The conflict transitions are checked as well:
  - The Nắng Suites, then TP.HCM → brand cleared with the note;
  - Pepper House, then Đà Nẵng → brand cleared;
  - Đà Nẵng, then Pepper House → city cleared;
  - Bare, then Đà Nẵng → Bare Hàn only;
  - reset → six;
  - an address such as `?brand=pepper-house&city=da-nang` loads to a valid state.

The existing `filter.test.ts` stays as it is and keeps passing.

Evidence levels used below: **confirmed** means read directly from the workbook or a Drive page. **Probable** means inferred from metadata. **Unverified** means only VNest can settle it.

How the Drive check was done: each of the 18 distinct folder links was opened anonymously (public "anyone with the link" access). From each page I read only the folder title, file names, MIME types, byte sizes and owner. I viewed thumbnails in the in-app browser. **No image was downloaded, saved or committed.** Pixel dimensions and file hashes were not measured, because both need the files. Every duplicate finding below therefore rests on metadata (file name and byte size), not on content.
